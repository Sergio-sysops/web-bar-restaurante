# La Plazuela · Web para bar-restaurante

Web de demostración para un **bar-restaurante "todo en uno"** (desayunos, menú del día, tapas y copas). El negocio es **ficticio**.

🔗 **Verla funcionando:** https://sergio-sysops.github.io/web-bar-restaurante/

## Qué incluye

- **La web cambia según la hora del día**: por la mañana enseña los desayunos, a mediodía el menú, por la tarde el tapeo y por la noche las copas (con portada nocturna).
- **"Abierto ahora / Cerrado"** calculado con el horario real, incluidos los cierres después de medianoche.
- **Carta digital por secciones** con los **14 alérgenos** obligatorios y un filtro **"solo sin gluten"**.
- **QR para las mesas**, listo para imprimir.
- **Pizarra** con las recomendaciones del día.
- **Menú del día** y **eventos de la semana** (fútbol, karaoke…).
- **Reservas por WhatsApp**: el cliente rellena el formulario y le llega al bar el mensaje ya escrito.
- **Cómo llegar** (Google Maps), botón de llamar y horario con el día de hoy resaltado.
- Pensada primero para el **móvil**, sin cookies de seguimiento y sin base de datos: rápida y gratis de alojar.

## Cómo se actualiza

Todo el contenido (carta, precios, horario, menú, eventos) está en un único archivo: `datos.js`. Cambiar un precio es cambiar un número.

## Tecnología

HTML, CSS y JavaScript sin frameworks. Se aloja gratis en GitHub Pages o Cloudflare Pages.
